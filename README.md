# 赫拉手帐 · HERA'S JOURNAL

![赫拉手帐图标](icons/icon-512.png)

> 身体有自己的潮汐，你只需要好好记录。

**赫拉手帐**是一个纯前端、本地优先的女性生理与情绪手帐。它没有账号、没有云端、没有追踪脚本，所有个人记录只保存在当前浏览器的 `localStorage` 里。

页面采用奶油白与燕麦色，圆角、轻阴影、柔和字体，像一本安静的手帐本；同时提供周期记录、疼痛翻译、健康科普、隐私保护和离线使用等实用功能。

---

## 功能一览

### 1. 周期与身体记录

- 42 格月历视图，可标记经期开始 / 结束。
- 根据最近一次经期与平均周期，用虚线标出**预测的下次经期日**；真实经期优先，不会被预测样式覆盖。
- 每日记录四种情绪：🌸 平静、🌧️ 委屈、🔥 暴躁、🥺 想被抱抱。
- 用 1–5 个 🩸 记录疼痛等级，并写下一句只给自己看的话。
- 记录后随机出现温暖的寄语；没有连续打卡压力。
- 最近 30 天疼痛与情绪折线图：Canvas 绘制，情绪用不同颜色的圆点标在疼痛点上方。

### 2. 把难受翻译成能被听见的话

- **就诊备忘录**：把“肚子痛得像被绞肉机绞，吃布洛芬没用”这类大白话，整理成更专业的主诉、现病史、用药与想问医生的问题。
- 支持一键复制，或下载一张干净的长图，方便拿给医生看。
- **免死金牌 · 请假条**：疼痛 ≥ 3 时出现，可生成给领导或老师的请假说明，包含疼痛程度、请假时长和工作 / 课程交接。
- **家属求生卡**：生成 1080×1440 的 Canvas 卡片，用更直接的方式告诉家人“今天需要怎样被照顾”。

### 3. 情绪照顾与隐私

- **防窥屏模式**：点击页头的眼睛按钮，日记、情绪、疼痛、日历统计等敏感信息会替换为 `***`；再点一次恢复。开启期间编辑框会锁定，避免误写。
- **5 级疼痛急救舱**：疼痛选到 5 级，或点击右下角“🆘 紧急舒缓”，进入全屏深色呼吸空间；包含 4-7-8 呼吸节奏与 Web Audio 生成的雨声。
- **时空信箱**：写日记时可以勾选“封存为时空信件（30 天后开启）”。到期后会自动出现一封过去的信；标记“经期开始”时，也可能提前收到一封被身体记住的信。
- **反焦虑夸夸机**：从身材、容貌、经期、内耗四个分类中随机抽取一句夸夸，可保存为 1080×1920 的手机壁纸。

### 4. 知识与数据

- **谣言粉碎机**：对“宫颈糜烂”“洗洗更健康”“痛经生个孩子就好”等常见说法给出温暖但明确的循证解释。
- **身体自检红绿灯**：鲜红、暗红 / 褐色、大血块、非经期出血四种情况，对应不同的科普说明与就医提醒。
- **女性健康百科**：当前内置 **296 条**知识点，覆盖 15 个分类、16 个 tab（含“全部”）。支持实时搜索、分类筛选、折叠卡片与键盘操作。
- **数据备份**：可导出每日记录为 JSON，并在换设备后导入合并；同一天以更新时间较新的版本为准。

## 快速开始

本项目不需要安装依赖，也不需要构建。

### 推荐方式：本地 HTTP 服务

在项目目录执行：

```bash
# Python 3
python -m http.server 8000

# 或者 Node.js
npx serve .
```

然后打开：

```text
http://localhost:8000/
```

> **为什么不能直接双击 `index.html`？**
>
> 健康百科通过 `fetch('./wiki-data.json')` 读取同目录 JSON。浏览器通常会以 CORS 限制阻止 `file://` 页面读取本地 JSON，因此直接双击打开时，百科区会提示“百科数据没有载入”。
>
> 通过 `localhost` 或 HTTPS 打开即可完整使用。PWA 的 Service Worker 也只能在 HTTPS 或 localhost 下注册。其他记录功能在 `file://` 下仍可工作，但百科和离线能力不可用。

### 部署到 HTTPS

把整个目录上传到任意静态托管服务即可，不需要后端。请确保 `index.html`、`wiki-data.json`、`manifest.json`、`sw.js` 和 `icons/` 保持在同一目录层级。

## 安装为 PWA

首次通过 HTTPS 或 localhost 打开后：

- **Chrome / Edge**：地址栏右侧出现安装图标，或打开菜单 → “安装赫拉手帐”。
- **Android Chrome**：菜单 → “添加到主屏幕” / “安装应用”。
- **iOS Safari**：分享 → “添加到主屏幕”。

安装后可全屏运行；首次在线加载完成后，页面外壳、图标和百科 JSON 会被 Service Worker 缓存，离线也能打开。

## 数据与隐私

### 本地存储

个人记录使用两个键：

| Key | 内容 |
| --- | --- |
| `heraJournal.v1` | 每日记录、经期标记、设置与备份元信息 |
| `heraLetters.v1` | 时空信箱的密封信件 |

每条每日记录大致包含：

```json
{
  "periodEvent": "start",
  "emotion": "calm",
  "pain": 3,
  "note": "今天允许自己慢一点。",
  "updatedAt": 1760000000000
}
```

- 没有账号、登录、云同步或设备指纹。
- 页面不会向第三方发送任何记录。
- 健康百科通过同源请求读取 `wiki-data.json`；这是静态资源加载，不是上传数据。
- 导出备份时，JSON 只包含每日记录与设置；**时空信件目前独立存储，不包含在导出文件中**。
- 清理浏览器站点数据、使用隐私模式或更换浏览器，都可能导致本地记录丢失。请定期导出备份。

### 导入与合并

- 支持导入本应用导出的 JSON 备份。
- 导入不会覆盖已有记录；同一天以 `updatedAt` 较新的版本为准。
- 损坏、非法日期或空记录会被跳过，并在导入确认框中提示数量。

## 健康百科数据

`wiki-data.json` 是一个纯 JSON 数组，每条记录包含四个字段：

```json
{
  "cat": "经期与内分泌",
  "q": "痛经止痛药怎么选？",
  "a": "……",
  "src": "ACOG 痛经指南；中华医学会妇产科学分会"
}
```

当前规模：

- 总计 **296 条**
- **15 个分类**：经期护理 10、避孕用药 19、妇科疾病 10、日常防护 7、疫苗筛查 6、常见症状 6、经期与内分泌 34、妇科疾病与筛查 34、避孕与两性健康 33、心理与情绪内耗 33、生活避坑与智商税 33、身体求救信号 33、就医避坑 13、校园心理 13、病耻感破除 12
- 页面按“全部 + 15 个分类”显示为 16 个 tab

### 修改百科数据

1. 直接编辑 `wiki-data.json`，保持为纯 JSON 数组；每条必须包含 `cat`、`q`、`a`、`src`。
2. 建议保证 `q` 不重复，并检查 JSON 语法。
3. 如果修改了 `index.html`、`wiki-data.json` 或其他被缓存的文件，请把 `sw.js` 中的 `CACHE_VERSION` 从 `v2` 改为新版本（如 `v3`），否则已安装的 PWA 可能继续使用旧缓存。
4. 重新加载页面；Service Worker 会在下一次访问时更新缓存。

百科渲染使用 `document.createElement` / `createElementNS` 与 `replaceChildren`，不通过 `innerHTML` 注入内容。

## 技术说明

- **原生 HTML / CSS / JavaScript**：无构建步骤、无框架。
- **Canvas 2D**：就诊备忘录长图、家属求生卡、夸夸壁纸、30 天疼痛情绪折线图。
- **Web Audio API**：急救舱雨声由浏览器实时生成，不加载音频文件。
- **`<dialog>`**：请假条、时空信箱、夸夸机等原生对话框。
- **Service Worker + Manifest**：PWA 安装与离线缓存。
- **响应式布局**：桌面、平板、手机三档；已检查 1440 / 768 / 390 px 下无横向溢出。
- **可访问性**：语义化按钮、键盘 tab 切换、`aria-*` 状态、`prefers-reduced-motion` 降级。
- **隐私模式**：JS 用 `***` 替换敏感文本并保存原值，关闭时恢复；CSS 负责星点遮罩与视觉降噪。

### 浏览器支持

建议使用较新的 Chrome、Edge、Safari 或 Firefox。

- PWA 安装与 Service Worker 需要 HTTPS 或 localhost。
- iOS 的 PWA 能力与桌面 Chromium 不完全一致。
- Web Audio 需要用户手势触发；部分浏览器会限制后台音频。
- `backdrop-filter` 在旧浏览器上可能降级为纯色背景。

## 常见问题

**百科区显示“百科数据没有载入”**

请通过 `localhost` 或 HTTPS 打开，并确认 `wiki-data.json` 与 `index.html` 在同一目录。直接双击 `file://` 打开时，浏览器通常会拦截本地 JSON 请求。

**页面能打开，但不能安装 PWA**

确认当前地址是 HTTPS 或 localhost，且 `manifest.json`、`sw.js`、图标文件路径正确。首次加载后刷新一次，等待 Service Worker 激活。

**修改后离线页面还是旧内容**

提升 `sw.js` 的 `CACHE_VERSION`，然后在浏览器 DevTools → Application → Service Workers 中更新，或关闭全部旧标签页后重新打开。

**数据会上传吗？**

不会。个人记录只写入当前浏览器的 `localStorage`。健康百科是静态同源 JSON，不包含用户输入。

**隐私模式里为什么不能写日记？**

这是有意的设计：防窥状态下输入框会锁定，避免在他人靠近时误输入或覆盖原文。退出隐私模式即可继续编辑。

**换手机怎么迁移？**

在旧设备导出 JSON，在新设备打开“数据安全”区域导入。时空信件目前不会随备份导出。
