# 赫拉手帐 · 身体日记

一个**只保存在本地**的女性周期、情绪与健康手帐。记录身体，翻译疼痛，粉碎谣言。

没有账号，没有服务器，没有上传。所有记录留在你自己的浏览器里，鼠标一关，它就只是你的。

---

## 这是什么

赫拉手帐是一个单文件 Web 应用（`index.html`，零依赖、零构建），用日历记录月经周期、复合情绪、疼痛与日记，并把这些零散的感受整理成**可以带去诊室的东西**：

- 用大白话描述疼痛，它翻译成医生看得懂的结构化备忘录；
- 用历史数据给出**带范围与置信度**的经期预测，数据不够时诚实地承认「不可预测」；
- 把反复出现的模式写成观察笔记，而不是诊断结论。

它不评分、不打卡、不制造焦虑，也不替你做医学判断。

---

## 功能

### 记录

| 模块 | 说明 |
| --- | --- |
| 日历 | 记录经期开始 / 结束、疼痛 0–5 级、备注；支持跨月查看、回到今天 |
| 复合情绪 | 同一天可以选任意多个情绪（平静 / 委屈 / 暴躁 / 想被抱抱），不再强迫二选一 |
| 可选扩展字段 | 睡眠、运动、用药、性生活、宫颈黏液，默认折叠，空着就不写入 |
| 「今天先不记」 | 当天不想记录时一键收起输入区，不产生任何数据，不写一句负罪感文案 |
| 周期阶段带 | 月经期 / 卵泡期 / 排卵期 / 黄体期，颜色 + 文字双标注，今天用圆点标记 |

### 看见

- **疼痛图表**：最近 30 天的疼痛与情绪折线。
- **诚实预测**：均值 + 标准差算出「预计 11 月 18–22 日（置信度：中）」的区间，而不是假装精确到某一天；变异过大（标准差 > 7 天）或完整周期不足 2 个时，直接停止预测并说明原因，绝不用 28 天硬推。
- **观察笔记**：累计 ≥ 3 个完整周期后，对比月经期 / 黄体期与其他阶段的疼痛、经前负面情绪频率，用「你记录到：……」的措辞呈现，只观察，不诊断。
- **身体自查**：按症状组合给出「什么时候该去医院」的分级提示。

### 带走

- **就诊备忘录**：把口述翻译成五段式（主诉 / 时间线 / 伴随症状 / 已尝试措施 / 关键问题）。支持胶囊标签点击改词、复制文本、导出长图、`打印 / 导出 PDF`（A4 灰度可读，页脚带「不构成诊断」声明）。
- **时空信件**：写给未来某一天自己的信，到解锁日才能打开。
- **家属求生卡**：给陪在身边的人一张「现在能做什么」的说明卡，可下载为图片。
- **请假条**：四个角色（领导 / 老师 / 导师 / 客户）、半天或数天、可填称呼，生成一条不卑不亢的消息。
- **谣言粉碎 & 知识库**：17 条常见健康谣言 + 296 条本地百科条目，支持搜索与分类。
- **夸夸机**：需要被夸一句的时候。

## 快速开始

1. 下载整个文件夹（或直接拿到 `index.html`）。
2. 双击 `index.html` 用浏览器打开即可使用。

想安装成独立应用（PWA、可离线、有桌面图标）时，需要经由 `http(s)://` 或 `localhost` 访问：

```bash
# 任选其一，在项目目录里执行
python -m http.server 8080
# 或
npx serve .
```

然后浏览器打开 `http://localhost:8080/`，地址栏出现「安装」提示即可安装。

> 直接双击（`file://`）也能完整使用，只是浏览器不允许 `file://` 注册 Service Worker，因此没有 PWA 离线安装。

## 文件结构

```text
赫拉档案/
├─ index.html          # 全部界面与逻辑（单文件，无依赖）
├─ sw.js               # Service Worker：只缓存页面外壳与图标
├─ manifest.json       # PWA 清单（名称、主题色、standalone、图标）
├─ wiki-data.json      # 百科补充数据（运行时按需合并，不联网）
└─ icons/              # 192 / 512 / maskable / apple-touch 图标
```

页面数据（你的记录）**不在这些文件里**，而在浏览器的 IndexedDB 中。

## 数据与隐私

### 默认：全部留在本机

- 记录写入 **IndexedDB**（数据库 `hera-journal`）；浏览器不支持时依次降级到 `localStorage`、内存，并在顶部给出提示。
- 没有任何联网请求；`wiki-data.json` 只在本地读取合并。没有统计、没有埋点、没有第三方脚本。
- 数据键名保持 `heraJournal.v1`（整份状态）与 `heraLetters.v1`（时空信件），导出的备份是标准 JSON，可自行检查。

### 可选：给记录加一把锁

「数据安全」面板里可以开启**本地加密（实验性）**：

- 数据密钥 DEK 使用 AES-GCM 256，不可导出，每条记录独立 12 字节 IV；
- DEK 被两把钥匙分别包裹：本机密钥（Device-KEK，存在 IndexedDB 的 `vault` 仓库）与主密码派生密钥（PBKDF2-SHA256，310000 次迭代 + 16 字节盐）；
- 日常打开靠本机密钥自动解锁，**不需要输入密码**；只有本机密钥丢失（清除了站点数据、换了浏览器）时才需要主密码；
- 主密码从不存储；DEK 从不写入任何存储介质。

需要诚实告知的边界：

> 清除浏览器数据 = 本机密钥丢失；忘记主密码且本机密钥丢失 = 数据无法恢复。

另外：**导出/打印的文件是明文**，加密只保护浏览器里的存储。导出前会有提示，请自行妥善保管。

### 防窥模式（眼睛图标）

一键遮住首页文案、情绪标签、疼痛描述、日历详情、备忘录、请假条与信件弹窗；身体日记输入框只做视觉遮罩，**不会改动你正在输入的内容**，关闭后原文完整恢复。

### 多标签页

同一浏览器开多个标签时，保存会通过 `BroadcastChannel` 通知彼此刷新，并做了合并与防抖，避免互相覆盖。加密开启时只广播「有更新」事件，不广播任何记录内容。

## 浏览器要求

- Chrome / Edge / Firefox / Safari 的近两年版本；
- 需要 JavaScript（页面在禁用 JS 时会明确说明）；
- 加密功能额外需要 `crypto.subtle` 与 IndexedDB；不满足时开关置灰并注明「当前浏览器不支持本地加密」；
- 多标签同步依赖 `BroadcastChannel`，不支持时静默降级为单页使用。

## 使用建议

- 经期只需标记「开始 / 结束」，其余交给日历自动着色；不确定的日子可以先不记。
- 描述疼痛时用大白话即可（「像被绞肉机绞」「一阵一阵地发木发胀」），备忘录会翻译成结构化语言；翻错了可以直接点标签改词。
- 想看趋势先攒 2–3 个完整周期；周期带与预测会随着记录变多慢慢长出来。
- 定期用「导出备份」存一份 JSON；换设备时用「导入」按日期合并，同一天以更新时间较新者为准。

## 开发说明

- 没有构建步骤：所有 HTML / CSS / JS 都在 `index.html` 内，只用浏览器原生 API。
- 存储层是异步封装（`Store`），业务代码只调 `get / set / remove / keys / clear`；加密开启后加解密在存储层自动完成，业务侧无感。
- 修改 `sw.js` 的缓存内容时请同步提升 `CACHE_VERSION`，否则旧外壳会被继续使用。
- 改完建议做一轮手测：新记录 → 刷新仍在 → 防窥开关 → 导出/导入 → 打印预览 → 加密开启/锁定/解锁。
