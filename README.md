# 赫拉手帐 · HERA'S JOURNAL

一个**只保存在本地**的女性周期、情绪与身体手帐。记录身体，翻译疼痛，粉碎谣言。

没有账号，没有服务器，没有上传。所有记录留在你自己的浏览器里。

---

## 这是什么

赫拉手帐是一个**单文件 Web 应用**（`index.html`，零依赖、零构建）：用日历记录月经周期、复合情绪、疼痛与日记，再把这些零散的感受整理成**可以带去诊室的东西**。

它不评分、不打卡、不制造焦虑，也不替你做医学判断。数据不够时，它会直接说「还不够」，而不是编一个看起来很像的数字。

## 功能

### 记录

| 模块 | 说明 |
| --- | --- |
| 日历 | 经期开始 / 结束、疼痛 0–5 级、备注；跨月查看、回到今天；非经期但有症状的日子，格子右下角有一个小圆点 |
| 月经量 | 主面板三档：少 / 正常 / 多，单选，再点一次取消 |
| 复合情绪 | 同一天可选任意多个情绪（平静 / 委屈 / 暴躁 / 想被抱抱），多选时格子显示「首个 emoji + 加号」 |
| 更多记录（可选） | 睡眠、运动、用药、性生活（无 / 已避孕 / 未避孕）、分泌物（干燥 / 粘稠 / 蛋清状）、体温、便便（正常 / 腹泻 / 便秘）、其他不适（腰酸 / 乳房胀痛 / 头晕）；默认折叠，空着就不写入、不占存储 |
| 体温校验 | 只接受 34.0–43.0 ℃；越界会轻提示并回退到上一次保存的值，绝不写进记录 |
| 「今天先不记」 | 当天不想记录时收起输入区，不产生任何数据，也不写一句负罪感文案 |
| 周期阶段带 | 月经期 / 卵泡期 / 排卵期 / 黄体期，颜色 + 文字双标注，今天用圆点标记 |

### 看见

- **疼痛图表**：最近 30 天的疼痛与情绪折线。
- **诚实预测**：均值 + 标准差得出「预计 11 月 18–22 日（置信度：中）」的区间，而不是假装精确到某一天；完整周期不足 2 个、或标准差 > 7 天时完全停止预测并说明原因，绝不拿 28 天兜底。日历可一键关掉预测。
- **观察笔记**：累计 ≥ 3 个完整周期后，比较月经期 / 黄体期与其他阶段的疼痛、经前负面情绪频率，用「你记录到：……」的措辞呈现，只观察、不诊断，附一句「带着这个模式去和医生讨论，可能会有所帮助」。
- **身体自查**：按症状组合给出「什么时候该去医院」的分级提示。

### 带走

- **就诊备忘录**：把口述翻译成五段式（主诉 / 时间线 / 伴随症状 / 已尝试措施 / 关键问题）。
  - 翻译引擎只提取**动词与感官形容词**（针扎、拧着、往下拽、发木发胀……），不猜名词比喻；否定句会拦下（「不是针扎的那种刺痛」不会变成刺痛）。
  - 预览里的部位、性质、VAS、病程、药名、效果、口述时间都是**胶囊标签**，点一下就能换成同类医学术语，也可以删掉；改动即时同步到正文、复制文本、长图与 PDF。
  - 口述与打卡记录**并列展示**：一致时合并成一句，不一致时各写一行，不会用打卡覆盖你的说法。
  - 支持复制文本、导出长图、`打印 / 导出 PDF`（A4 灰度可读，页脚带「不构成诊断」声明）。
- **时空信件**：写给未来某一天自己的信，到解锁日才能打开。
- **家属求生卡**：给陪在身边的人一张「现在能做什么」的说明卡，可下载为图片。
- **请假条**：四个角色（领导 / 老师或辅导员 / 导师 / 客户或合作方）、半天或数天、可填称呼，生成一条不卑不亢、带一句话交接的消息。
- **谣言粉碎 & 知识库**：17 条常见健康谣言 + 296 条本地百科条目，支持搜索与分类。
- **夸夸机**：需要被夸一句的时候。

## 快速开始

1. 拿到整个文件夹（至少需要 `index.html`）。
2. 双击 `index.html`，用浏览器打开即可使用。

想安装成独立应用（PWA、可离线、有桌面图标）时，需要经由 `http(s)://` 或 `localhost` 访问：

```bash
# 任选其一，在项目目录里执行
python -m http.server 8080
# 或
npx serve .
```

浏览器打开 `http://localhost:8080/`，地址栏出现「安装」提示即可安装。

> 直接双击（`file://`）也能完整使用，只是浏览器不允许 `file://` 注册 Service Worker，因此没有 PWA 离线安装。

你的记录**不在这些文件里**，而在浏览器的 IndexedDB 中。

## 数据与隐私

### 默认：全部留在本机

- 记录写入 **IndexedDB**（数据库 `hera-journal`，仓库 `meta` / `records` / `letters` / `vault`）；浏览器不支持时依次降级到 `localStorage`、内存，并在顶部给出一条可关闭的提示条。
- 存储层统一为异步的 `Store`（`get / set / remove / keys / clear / ready`），业务代码不直接碰存储；加密开启后加解密在存储层自动完成。
- 空间不足时只清理本应用自己的旧备份元信息，绝不删除 `records` / `letters`；仍写不进去就降级为「仅本页有效」并提示立即导出。
- 数据键名保持 `heraJournal.v1`（整份状态）与 `heraLetters.v1`（时空信件）；导出的备份是标准 JSON，可自行检查。
- **应用代码不主动联网**。`wiki-data.json` 只在本地读取合并；页面通过 CSP 限定了唯一的外部来源为本机 `'self'`。

### 托管平台说明

如果你把它放在 GitHub Pages 之类的静态托管上，**托管方可能记录基础访问日志**（IP、时间、User-Agent），这不在应用控制范围内。应用本身不发起任何网络请求，也不含统计、埋点或第三方脚本。

### 可选：给记录加一把锁

「数据安全」面板里可以开启**本地加密（实验性）**：

- 数据密钥 DEK 使用 AES-GCM 256，`extractable: false`，每条记录独立 12 字节 IV；
- DEK 被两把钥匙分别包裹：本机密钥（Device-KEK，存在 IndexedDB 的 `vault` 仓库）与主密码派生密钥（PBKDF2-SHA256，310000 次迭代 + 16 字节盐）；
- 日常打开靠本机密钥自动解锁，**不需要输入密码**；只有本机密钥丢失（清除了站点数据、换了浏览器配置）时才需要主密码；
- 主密码从不存储；DEK 从不写入任何存储介质；加密只作用于 `records` 与 `letters`，`meta` 与 `vault` 不加密；
- **开启前的备份护栏**：如果你已经有记录、却从未导出过备份，开启加密前会先拦一次，提示先去「导出我的数据」。也可以确认风险后直接开启。
- 面板里可「立即锁定」：清掉内存中的密钥，显示解锁层，但保留本机密钥以便下次自动解锁。

需要诚实告知的边界：

> 清除浏览器数据 = 本机密钥丢失；忘记主密码且本机密钥丢失 = 数据无法恢复。

另外：**导出与打印的文件是明文**，加密只保护浏览器里的存储。导出前会有一次「导出文件是明文，请妥善保管」的提示。

### 防窥模式（眼睛图标）

一键遮住首页文案、情绪标签、疼痛描述、日历详情、备忘录预览、请假条与信件弹窗、月经量与体温等敏感内容。

身体日记、用药与体温输入框只做**视觉遮罩**（字迹透明 + 遮罩层），不会改动你正在输入的内容，也不会破坏输入法；关闭后原文完整恢复。防窥期间备忘录标签菜单、请假条等入口一律不可用；加密未解锁时收到的多标签广播只刷新事件，不会把内容画到屏幕上。

### 多标签页

同一浏览器开多个标签时，保存会通过 `BroadcastChannel` 通知彼此刷新，并做了合并与防抖，避免互相覆盖；正在输入日记时会先合并字段、稍后再重绘，不会抢走你的光标。加密开启时只广播「有更新」事件，不广播任何记录内容；未解锁的标签页收到广播也不会写入或渲染。

## 浏览器要求

- Chrome / Edge / Firefox / Safari 的近两年版本；
- 需要 JavaScript（禁用时页面会明确说明）；
- 加密额外需要 `crypto.subtle` 与 IndexedDB；不满足时开关置灰并注明「当前浏览器不支持本地加密」；
- 多标签同步依赖 `BroadcastChannel`，不支持时静默降级为单页使用。

## 使用建议

- 经期只需标记「开始 / 结束」，其余交给日历自动着色；不确定的日子可以先不记。
- 描述疼痛用大白话即可（「像被绞肉机绞」「一阵一阵地发木发胀」），备忘录会翻译成结构化语言；翻错了可以直接点标签改词或删词。
- 想看趋势先攒 2–3 个完整周期；周期带、预测与观察笔记会随着记录变多慢慢长出来。
- 定期用「导出我的数据」存一份 JSON；换设备时用「导入数据」按日期合并，同一天以更新时间较新者为准。
- 如果打算开启加密，**先导出一次备份**——这比记住密码更稳妥。

## 开发说明

- 没有构建步骤：所有 HTML / CSS / JS 都在 `index.html` 内，只用浏览器原生 API，不引入任何第三方库。
- 存储层是异步封装（`Store`），并内置了 IndexedDB → `localStorage` → 内存的三级降级；配额不足时的淘汰策略只针对本应用的旧备份元信息。
- 加密相关的密钥生成、包裹与加解密都在 `Vault` 模块中，业务代码只与 `Store` 交互。
- 修改 `sw.js` 的缓存内容时请同步提升 `CACHE_VERSION`，否则旧外壳会被继续使用。
- 改完建议做一轮手测：写一条记录 → 刷新仍在 → 防窥开关 → 导出/导入 → 打印预览 → 加密开启 / 锁定 / 解锁 → 多标签同时打开。
